# Phenomenological inference reference

These JSON summaries preserve the nine-parameter, seed-43 inference
comparison before the physical planet-lens experiment. The injected event
uses `t_E=16.235` days, `rho=.01`, a W149-reference source magnitude of
24.744, and independent annual-parallax parameters. Stellar radius,
temperature, distance, and extinction were not tied to that magnitude.

The results measure sampling efficiency for this controlled event. They do
not establish a physical lens mass or a Roman instrument forecast. The
north parallax component is effectively prior dominated.

`manifest.json` records the original hashes of reports, input data, posterior
samples, and figures. Historical CSV data, posterior archives, and rendered
figures remain local and are excluded from Git and source distributions.
Current results are in [outputs](../../outputs/).
