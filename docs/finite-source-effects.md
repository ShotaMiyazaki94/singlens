# Finite-source effects

The source radius is $\rho=\theta_*/\theta_E$. Differential magnification
across the stellar disk changes both the light curve and the image centroid,
particularly during a source transit.

## Usage

(choosing-a-solver)=
### Solver selection

Uniform and linear limb-darkened models use a precomputed joint table bundled
with the package. `Model(source="linear")` evaluates photometry and astrometry
without preparation. Point sources are analytic; pure `mu2` sources use FFTLog.

| Backend | Use |
| --- | --- |
| `solver="table"` | Bundled table for uniform/linear sources with `1e-6 <= rho <= 10` and `0 <= u/rho <= 1e8`. |
| `solver="fft"` | FFTLog for uniform, linear, or pure `mu2` sources. |

The solver and its numerical settings are fixed during a fit. Outside its
domain, the table returns NaN.
`rho=0` gives the analytic point-source limit. `Model(source="point")` omits
finite-source parameters entirely.

(using-a-fixed-solver)=
### Photometry and astrometry

Enable float64, construct a model, and pass event parameters to its methods:

```python
import jax
jax.config.update("jax_enable_x64", True)
import jax.numpy as jnp
from singlens import Model, Parameters

model = Model(source="linear")
params = Parameters(t0=0., u0=.04, t_e=30., rho=.1, a1=.5)
times = jnp.linspace(-3., 3., 64)
A, shift = jax.jit(model.joint)(times, params)
dA, dshift = jax.jacfwd(model.joint, argnums=1)(times, params)
```

The outputs preserve input shape; shifts are relative to the unlensed source
in Einstein-radius units. For separate observables or evaluation at supplied
positions, see the [API](api.md).

(from-lensing-shifts-to-observed-astrometry)=
The [astrometry guide](astrometry.md) adds sky rotation, angular scaling,
source motion/parallax, and blended light to this source-only lensing signal.

## Methods

### Joint basis tables

(flux-and-astrometry-from-the-same-source)=
(concentric-disks)=
The table combines uniform and pure-$\mu$ brightness profiles using
$\Gamma=2a_1/(3-a_1)$, where $\mu=\sqrt{1-(r/\rho)^2}$.
Its bases are generated by direct quadrature using
[Wang's disk-mixture identity](https://arxiv.org/html/2607.12483v1#S2.E7).
This has no small-source assumption. The centroid combines
[flux-weighted image moments](theory/index.md#astrometric-centroid-shift)
before dividing by total magnification.

Cubic interpolation uses 192 radii and 947 separation ratios, with extra
sampling near contact. Analytic point-source terms preserve the distant
behavior, and an even separation coordinate gives regular Cartesian
derivatives at alignment. Radius-dependent spline coefficients are shared
across epochs. The 5.03 MB packaged table includes both fluxes
and astrometric moments; its [encoding and generation](https://github.com/ShotaMiyazaki94/singlens/blob/main/tools/validation/README.md#joint-table-representation)
are documented separately.

### Photometry-only alternatives

The [Gould–Yoo approximation](https://doi.org/10.1051/0004-6361/200912007)
uses the small-source limit. The comparison below also tests direct quadrature
and a two-channel photometry table. These are reference methods for the
photometry experiment; their accuracy and timing are measured separately from
the bundled joint table. Higher-order small-source corrections and refined
grids are included in the downloadable report.

## Validation

The measurements use float64 on an Apple M5 Pro CPU, Python 3.12.10,
JAX 0.11.2, and NumPyro 0.22.0. Joint tables were generated with 96/64 disk
quadrature. Reported maxima describe the sampled domain, not uniform error
bounds.

### Independent accuracy measurements

The value grid has 1,074 samples: eight radii from `1e-6` to 10,
`a1=0,0.5,1`, alignment, contact offsets down to `|u/rho-1|=1e-6`, and wings
including fixed `u=0.1,1,10,100`. References independently integrate source
brightness and image moments.

The bundled table's maximum sampled relative magnification error is `1.28e-7`.
The figure below compares astrometric errors, derivatives, and runtime.

Gradient checks use a separate grid at `a1=0.5`, approaching contact to
`|u/rho-1|=1e-4`. The metric takes the largest absolute Cartesian Jacobian
entry error, multiplying position/radius derivatives by `rho` and leaving
the limb-coefficient derivative unscaled. Independent reference uncertainty
reaches `3.1e-8 theta_E`. The [joint report](#simultaneous-inference) includes
reference convergence and additional quadrature orders and table grids.

Three limits matter for inference:

- At exact contact, a nonzero uniform-brightness edge has singular position
  and radius slopes. Finite quadrature and splines cannot reproduce them;
  those slopes are excluded from the comparison.
- The largest table gradient errors occur near contact at `rho=10`.
  Table endpoints have one-sided spline derivatives. FFT smoothing also
  biases contact values and derivatives.
- In weak wings, finite-source radius derivatives can be smaller than
  roundoff noise (about `1e-8` absolute in these checks). Use absolute or
  physically scaled errors when derivatives vanish.

### Evaluation speed

The right panel times a joint photometric/astrometric scalar objective and
its position, radius, and limb-coefficient gradients for a transit with `rho=1`.
Each point is the median of 25 synchronized calls, excluding compilation and
table construction. The table is about 8× faster than FFTLog at 512 epochs.
In a separate 2048-epoch weak-wing check, FFT's analytic approximation is
faster: 0.300 versus 0.367 ms. Timings use the stated settings; the methods
do not have matched errors.

### Simultaneous inference

Two synthetic experiments fit 40 epochs of flux and two-component astrometry:
a transit (`rho=.1, u0=.04`) and weak wings (`rho=.001, u0=.3`). Each fits
`rho`, `u0`, `a1`, `theta_E`, source flux, `t0`, and two astrometric zero points.
Timescale and orientation are fixed; blending, source motion, and annual
parallax are omitted. Signals come from independent integration, with
common priors and data across methods.

| Method | Transit: minimum ESS/s | Weak wings: minimum ESS/s |
| --- | ---: | ---: |
| FFTLog | 101 | 441 |
| Direct quadrature | 78.6 | 48.7 |
| Bundled basis table | 1288 | 1200 |

Runs use two chains, 350 warmup iterations, and 500 draws per chain.
Sampling ESS/s includes compilation of the sampling executable; including warmup
gives table/FFT speed ratios of 8.84 and 2.88. Solver setup and offline
generation are excluded. All 12 runs across six methods have zero divergences
or tree-depth saturation, with maximum R-hat below 1.004.

The table and direct 64/32 posterior means differ by at most 0.044 posterior
standard deviations. At the injected state and posterior mean, table
log-likelihood errors are at most `1.12e-5` (transit) and `1.42e-10` (wings).
These results describe the two simulated datasets. The
{download}`joint report <_static/astrometry-methods-summary.json>` contains
all methods, noise/priors, timings, reference stability, and diagnostics.

### Photometry-only comparison

The photometry experiment tests six radii from `1e-4` to 10 and
`a1=0,0.5,1`. Its basis table has 96 × 314 points and two photometric channels,
generated with 64/32 quadrature; it is distinct from the bundled joint table.

```{figure} _static/finite-source-methods.png
:alt: Photometry-only flux and gradient accuracy, and batched gradient runtime

FFTLog (4096 bins), conventional Gould–Yoo, direct quadrature (64/32), and
the photometry basis table (96 × 314): flux errors for `u/rho<=3`, scaled
gradient errors, and warm value/gradient runtime at `rho=.01`.
```

Here gradient errors are scaled by `rho/A` for position/radius and `1/A`
for the limb coefficient. Exact-contact slopes and unsupported series points
are excluded. The {download}`photometry report <_static/finite-source-methods.json>`
includes all resolutions, higher-order Gould corrections, and a four-parameter
NUTS experiment. At `rho=.1`, those corrections reduce sampled Gould–Yoo flux
errors from `1.25e-3` to `2.75e-5` and `1.88e-7`.

## Reproducibility

(reproducing-the-comparisons)=
(custom-tables)=
Run the comparisons from a source checkout with validation dependencies installed:

```bash
python -m tools.validation.astrometry_methods --with-tables --nuts
python -m tools.validation.finite_source_methods --with-table --nuts \
  --nuts-methods fftlog gould_o4 disk_32_16 basis_table
```

Reports go to `tools/validation/outputs/`. See the
[validation instructions](https://github.com/ShotaMiyazaki94/singlens/blob/main/tools/validation/README.md)
for partial reruns, table generation, and reference checks. The packaged table
records its generating settings and provenance.
